# Itim Buffet

Next.js + Supabase application for an ice-cream buffet ordering flow.

## Routes

- `/` Landing Page
- `/generate-qr` Generate table QR codes
- `/kitchen` Kitchen order screen
- `/order/1` Example table-order page

## Required Vercel Environment Variables

- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`

Do not put Supabase service-role keys in this project or in client-side code.
